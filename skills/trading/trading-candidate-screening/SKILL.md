# Trading Candidate Screening

扫描分达标（TRIGGER≥60 / WATCH≥46）≠ 一定建计划。选完候选、跑完 trading-analysis 后，生成 plan 前先做位置质量检查。对每个进入执行层的候选，必须先把假设触发价、保护线、TP1/TP2和取消条件数值化，并实际计算 R 值；不能用“方向正确”或“位置不佳”的文字判断替代数值验证。不达标 → 标 WATCH_ONLY + 写明"等什么条件复查"，不硬建。

## 不合格模式（直接判 WATCH_ONLY，不建 plan）

1. **破位空但已超卖**：4h RSI < 30（超卖）且现价距前低 < 1 ATR → 追空位置差。
   - 复查条件：等反抽到跌破位/短均线阻力（如 1h MA7）再评估
   - 例：AAVE 2026-08-06，S78 全场最高分，4h RSI 29.4 + 距前低 0.5% → 不建
2. **回踩多但止损距离过大**：止损须 ≥ 1 ATR（低价高波动币 15m ATR 常 ≥ 3%），若 TP1（最近结构位）收益 < 1.2R → 计划 R 不达标。
   - 复查条件：等价格实际跌到回踩区企稳后，用更近止损（回踩低点下方）重估
   - 例：COTI 2026-08-06，L52 4h/1d 多头排列，15m ATR 3.4% 导致回踩止损 5.3%、TP1 仅 0.65R → 不建
3. **追高/追空镜像**（与记忆规则一致）：高分+24h涨幅过大+1h/4h RSI双超买+巨量分歧 → 不建；跌幅过大+15m/1h RSI双超卖+巨量阴线+费率转负 → 不建。
   - 扫描阶段即可排除：24h 涨幅 +30% 以上的高分多、跌幅 -25% 以下的高分空，直接跳过
4. **破位空但短线超卖贴下轨**：15m/1h RSI < 35 且现价贴/破 1h 布林下轨、破位低点刚形成（近1-2根K线砸出）→ 追在地板上。
   - 与模式1区分：4h RSI 可能未到30（如42），模式1漏判；此条看**短线**RSI+布林位置
   - 复查条件：等反抽到阻力簇（15m阻力/1h前支撑转阻力）受阻再评估，不直接破位空
   - 例：HYPE 2026-08-09，S70，4h RSI 42 但 15m RSI 33 + 贴1h布林下轨 + 24h低刚砸出 → 建了破位空，用户拿另一模型交叉验证后删除
   - 量化"贴前低"：现价距前低 < 0.3 ATR = 贴脸无缓冲（追空），≥ 0.5 ATR = 有缓冲可建。对照：AAVE 08-14（4h RSI 36、15m RSI 28.8、距前低 0.2 ATR）→ WATCH_ONLY；UNI 08-14（15m RSI 47 中性、距前低 0.63 ATR）→ 正常建破位空且当天盈利
5. **刚平仓币再入场**：该币 24h 内刚止盈/止损（查 trading-history 或 userTrades）且现价在我方出场价上方 → 追高接回自己刚卖的币，排除。
   - 复查条件：价格回踩至出场区域下方企稳，按新的回踩结构重估
   - 例：WLD 2026-08-10，14:33 TP2 0.3429 止盈离场，15:23 扫描仍 L70、现价 0.3481 高于出场价 → 排除
6. **破位空 R 结构压缩**（判定动作：先算 R 再出口——止损=反弹高点/1h 结构上方，TP1=下方最近强支撑，TP1 落支撑上/下方或机械位 → 不建）。三种形态：
   - ①破位已走完大半+现价反弹回破位区上方，RSI 可以不超卖（XRP 例：15m RSI 46），杀死计划的是 R 结构压缩，不是超卖。例：XRP 2026-08-10，S78，破位低点 1.0228 已破且反弹至 1.0296，止损 1.0305 后 TP1(1.2R)=1.0118 正砸日线强支撑 1.012 → 不建
   - ②触发位到第一支撑太近：TP1 对齐第一支撑 < 1.2R，止损怎么收都救不回来或被迫贴阻力（易扫/假破）。例：SUI 2026-08-16，S78，1h 低 0.6742 → 4h 前低 0.6713 仅 0.5%，止损 1h 结构上方 1% → 0.5R；DOGE 同轮 S68，触发 0.06947 → 4h 低 0.06879 仅 1.1%，止损须收贴阻力 0.06999 才够 1.2R，假破风险高 → 均不建
   - ③破位后下方真空：前低本身就是日线区间低，下方无任何支撑参考，TP1 只能机械 1.2R（违 ZEC 禁手）。例：UNI 2026-08-16，S68，4h 前低 3.162=日线区间低，破位后下方真空 → 不建
   - 多头镜像：突破位=可见区间高点且上方无结构时，先拉日线长历史（`api_get('/fapi/v1/klines', {'symbol':S,'interval':'1d','limit':200})`）验证上方阻力簇真实存在，再算 R；TP1 R<1.2 → 不建。例：WLD 2026-08-17，L78 突破多，200日历史确认上方 0.379-0.403 阻力簇，结构止损算出 TP1 仅 1.03R → WATCH_ONLY（复查：回踩 0.350-0.355 缩量企稳后用近止损重估）
   - 复查条件：放量跌破该支撑并站稳其下（空间打开）再评估；或反弹至阻力簇明显受阻另议
7. **反弹多但个币自身日线空头排列**：日线 MA7<MA25 + 日线 RSI 偏弱（<45）+ 超跌反弹后横盘缩量滞涨 → 即使回踩 R 达标（≥1.2R）也不建。与退潮期大盘纪律区分：大盘弱但个币日线多头排列的强势龙头可建（LINK 08-15 例，日线刚转多头排列 → 回踩计划正常建）；个币自己日线都空头排列的反弹是"弱中弱"，不建。
   - 复查条件：日线收盘站上 MA25（转势确认）后回踩企稳再评估；或放量突破反弹高点站稳另议
   - 例：NEAR 2026-08-15，L58，回踩多 R=2.7R 达标，但日线 MA7<MA25、RSI 40.5、1.536→1.669 反弹后横盘 3 天缩量滞涨 → WATCH_ONLY
   - **判据须三要素齐备才判**：只有日线 MA7<MA25 但反弹**刚放量启动**（4h 大阳、非横盘缩量滞涨段）不算——AAVE 2026-08-18 例：日线 MA7<MA25、RSI 46.3（≥45 边缘）、4h 放量 2.51x 大阳刚启动 86.3→88.4 → 回踩多正常建（TP1 3.0R）。区分关键词：滞涨段（反弹走完横盘缩量）vs 启动段（放量大阳、动能新起）
8. **破位空但费率极端负（空头拥挤）**：funding < -0.003 级别 = 空头过度拥挤，轧空反抽风险高 → 不建。
   - 例：HOME 2026-08-16，S62，费率 -0.0051 → 不建
9. **崩盘反弹中的高波动币**：4h 区间振幅 >100%（近期崩盘后反弹途中），破位空假破风险极高 → 不建。
   - 例：TUT 2026-08-16，S60，4h 振幅 165%（0.0757→0.0285→0.0309 反弹中）→ 不建
10. **大盘 15m 放量下压时的多头批量淘汰**：BTC/ETH 日线空头排列且 15m 量比>1.5、主动买盘<0.48（放量下跌）时，多头候选（即使 L74）大概率被 market_filter 拦 → 扫描阶段整体降级，fetch_klines 预算留给顺势方向，别浪费在多头深挖。
   - 例：2026-08-16 扫描，HYPE L74/LINK L64/WLD L64 三个多头候选全灭于环境关（逆势+filter 会拦）
   - **对称场景（大盘 15m 放量上攻→空头降级）**：BTC/ETH 量比>1.5 且买盘>0.52 时，空头候选整体降级（filter 拦空），多头放行；已有空头计划即使触发也会被 filter 挡——如实告知用户"触发会被拦"而非报故障。例：2026-08-18 BTC L68 1h 量比 3.19 放量突破 → AAVE/LINK 回踩多正常建，AVAX 已有破位空计划提示触发也会被拦
11. **突破计划风险额超标**：现价接近触发位只提示复核，**不是独立禁手**。先从触发价计算：`qty=(10×杠杆)/触发价`，`风险额=qty×|触发价−结构止损|`；风险额 >2.6U → WATCH_ONLY。风险额合格仍须继续检查 TP1≥1.2R、结构空间、位置、量价、市场过滤与拥挤度。
   - ⚠️ **统一计算口径**：R 和风险额一律从 `entry_trigger` 算，禁止用现价。止损优先取触发位下方最近且有效的回踩低点（可来自15m或1h），同时须容纳正常 ATR 波动；禁止机械固定为15m前低，也不能无依据扩大到更远阶段低点。
   - 复查条件：放量突破站稳后，以突破位下方结构止损重算；或等待回踩企稳后，以新回踩低点重估。案例见 `references/incident-log.md`。
12. **放量突破但短线双超买+巨量已顶到区间最高点**：突破本身是好结构，但若突破瞬间 15m/1h RSI 双超买（>70）+ 15m 量比 >5 巨量 + 现价已顶到 4h 区间最高点（距高点 <0.2%）→ 追在突破最高点，回踩风险大。
   - 与模式3区分：24h涨幅可能不大（<15%），杀死计划的是**短线**RSI+巨量+顶格位置，不是 24h 涨幅
   - 复查条件：等回踩突破位缩量企稳、RSI 从超买回落 → 再评估回踩多
   - 案例见 `references/incident-log.md`。

## 禁手先例要复核（不按币种记忆排除）

禁手规则判的是**指标状态**，不是币种名。曾被某禁手模式拒绝的币，后续扫描再现时必须重算该模式当时命中的指标现值；条件不再成立 → 正常建。
- 例：PAXG 曾按追高禁手被拒（24h涨幅小但 4h RSI≥80 + 日线上轨外）；08-10 再现时 4h RSI 67.6、日线布林中轨上方 → 禁手条件不成立，正常建计划并监控

## 输出纪律

- WATCH_ONLY 候选必须在汇总里带复查触发条件（"反抽到 X 再评估"/"回踩到 Y 再评估"），不是放弃该币
- 已建计划 vs WATCH_ONLY 分开列；WATCH_ONLY 不建 Cron、不写 plan 文件
- 对扫描分≥60且进入最终比较的候选，否决时必须同时给出**数值化计划草案**（触发价、结构止损、最近结构TP、风险额与R），不能只报RSI/涨跌幅等禁手标签；若因追高或超卖无需建plan，也要说明复查价位。比较“是否优于现有计划”时，统一用触发价口径并排比较风险额、TP1 R、位置和动能，禁止拿现价R对现有触发计划R。
- 若结论是“结构勉强合格但不优于现有计划”，必须明确它为何不构成新增计划（例如日线超买、动能缩小、近端阻力密集、相关性重叠），并保留现有计划不自动替换。
- 用户常拿另一对话框的模型结论来交叉验证（2026-08-09 曾据此删掉 HYPE 破位空）。收到时逐候选对照双方结论，分歧处说明各自依据，把最终取舍交给用户（保持/改观察哨兵/删除），不硬辩
- **高分候选初筛跳过也必须当场给否决理由**，且理由用 R/结构数据、不用印象词（08-18 PAXG 例：L74 全场最高分，初筛写"黄金币与大盘相关性低"未给数据 → 用户质问"有没有跳过环节"，补验后真实理由=24h高到日线区间高仅0.26%空间致任何止损凑不出TP1≥1.2R）。用户会问"为什么不选分最高的"——初筛跳过≠不用交代；"相关性低""波动小"这类印象词不算理由，须 K 线/R 数据支撑

## 与流程的衔接

- 前置：binance-market-scanner 扫描 → trading-analysis（fetch_klines 深度分析）
  - 读扫描 JSON 前先看 `references/scan-json-structure.md`：results/topLong/topShort 都是嵌套结构（`r['long']['score']`），只有 summaryRows 是扁平键（`longScore`/`m15Close`…）；对嵌套数组用扁平键 .get() 会静默全返回 None 不报错（08-17 例：排名排序全靠 None，白跑一轮），混用会 KeyError 或静默错排
- 后置：合格候选 → trade-execution-planner 生成 plan → 验证拦截 → 建监控 Cron
- 本技能是 trading-analysis / trade-execution-planner 的"入口闸门"，它们自身的 SKILL.md 未收录这些模式（用户自有技能，待 adopt）

## 市场状态方向纪律（退潮期）

BTC/ETH 4h/1d 空头排列（退潮期）时，逆势多单即使全周期多头排列也易跌破失效线零成本出局（08-14：BNB/XMR 两单同日连续失效，UNI/LTC 顺势空全盈利）。但"弱市禁多"回测被否（被拦组 +8.45U），故不硬禁逆势多：① 靠 market_filter 兜底（BTC 转强才放行）；② 明确预期"可能失效"，不重仓押单边。

**强势币集体超买 + 空头全线退潮 = 高潮/超买阶段（不追多、不追空、空仓等回踩）**：识别信号为①多头榜 Top5 多数日线 RSI≥75，命中追高禁手；②空头最高分 <60，且多为 NEUTRAL/WATCH。此时多头不追、空头无顺势标的，等待强势币回踩企稳；输出口径："空仓观望正是这个位置该做的事，不是没信号，是信号都到了不该追的阶段"。验证案例见 `references/incident-log.md`。
