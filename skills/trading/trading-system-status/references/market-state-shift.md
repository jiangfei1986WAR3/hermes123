# 大盘状态切换与分数变化（2026-08-06 夜实测）

## 现象

BTC/ETH 大盘状态切换（如 NEUTRAL → LONG_WATCH / LONG_TRIGGER）时，扫描高分榜会**整体大幅变动**，属正常市场退潮/转多信号，不是系统故障：

- 2026-08-06 下午（18:16）：BTC/ETH 34/24 NEUTRAL，空头高分爆发（AAVE S78、WLD S70、SUI S78、FIL S70）
- 2026-08-06 晚（20:46）：BTC/ETH 48/24 LONG_WATCH（转多），空头分数普遍回落（AAVE S78→S60、WLD S70→S60、SUI 掉出榜），多头分数上升（PAXG L60→L72）

## 处置规则

1. **旧方向计划失去触发概率时保留监控让其自然过期**，不手动干预（如大盘转多后 WLD 空单价格反弹、迟迟不触发——plan 有 expires_at 会自行作废）
2. 重新扫描选候选时以**最新一轮分数**为准，不参考旧轮排名
3. 向用户解释分数变化时说明"大盘状态切换导致"，避免被误读为系统不稳定
