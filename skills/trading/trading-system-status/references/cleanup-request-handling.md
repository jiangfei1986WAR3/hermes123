# 用户下令清除监控/计划时的处置（08-18 SOL 例）

用户口头下令"清除X监控和计划"时，先查 X 是否有持仓：

- **X 无持仓**：五样全清（Cron + 脚本 + plan + state + 事件），照常执行。
- **X 有持仓**：⚠️ 先提示"删 plan = 移保本断链"（TP1 成交后 SL 不会自动移入场价，XRP 08-08 例），**不直接执行**。唯一有害动作 = 删有持仓币的 plan 文件；停 Cron、删脚本、删 state、删事件均无害（持仓托管链靠 plan 文件，信号监控停用不影响）。
- 08-18 实录：用户下令"清除 SOL 监控和计划"→ 提醒后用户立即撤回（"那就别删 我说错了"）。**结论：提醒是必要步骤不是啰嗦，用户未必记得断链风险；先说明影响面再动手，符合用户"对系统改动谨慎"的偏好。**
