# 规则回测法（08-10 验证）：复盘产出过滤规则前，先用实盘账本模拟

复盘给出"闸门/过滤"类建议（如"X 条件时禁止做多"）前，**必须用 round-trip 账本模拟**，理论合理不算数。

## 方法
1. 从 `roundtrip-rebuild.md` 口径拿到全部 round trip（含入场时间戳）
2. 对每笔按规则输入在**入场时刻**打标签。注意：入场时刻状态 ≠ 持仓期间走势（两个口径结论可能相反，08-10 实例：入场时 BTC 弱 ≠ 持仓期 BTC 跌）
3. 分组统计：被拦组的笔数 + pnl + 手续费；保留组的胜率 + pnl
4. 阈值敏感性：关键阈值跑 3-4 档，结论须同向才稳（08-10 横盘档 0.3%/0.5%/0.8%/1.2% 全同向亏损递增 → 扎实；若换阈值就翻盘 → 样本不足，不实施）
5. 单笔支配检查：某档盈利 85% 来自一笔（BEAT +11.25 例）→ 结论标注为"脆"，不作为硬规则依据

## 判定标准
- 被拦组净盈利为正 → 规则会拦掉好单，否决（"弱市禁多"实例：拦 11 笔合计 +8.45U，砍 27% 交易量，否决）
- 被拦组全负且阈值不敏感 → 规则有数据支持，但样本 <30 笔仍建议先"只记录不拦截"积累标签样本
- 验证期用户要多交易 → 任何砍量的闸门天然逆需求，默认倾向纯记录档

## 数据拉取
BTC 环境：`/fapi/v1/klines` interval=4h，起点前推 25 根（MA25 需 100h 前置），只保留已收盘 K 线（close_time <= now）。
