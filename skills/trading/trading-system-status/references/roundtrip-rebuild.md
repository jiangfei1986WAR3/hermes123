# Round-trip 重建审计法（2026-08-10 验证）

统计"完整交易笔数/战绩"时的标准方法，替代旧的日志计数法。

## 步骤

1. 按天分片拉全量 userTrades（startTime/endTime 跨度大 → 400 错误；不带 startTime 只回近期 ~85 条）。去重 key=(symbol, id)
2. 按 (symbol, positionSide) 分组、按 time 排序
3. 逐笔重建持仓：LONG 用 BUY 开/SELL 平；SHORT 用 SELL 开/BUY 平；持仓量归零 = 完成一笔 round trip
4. 系统战绩 = qty>0 的 round trip；qty=0 的孤立平仓 = 启动前遗留仓（TRX 例）剔除

## 陷阱

- **重复计入**：round trip 初始化时若把首笔开仓成交预置进 fills 列表后又 append 一次 → 首笔双计、加权入场价翻倍（实测 RE 显示 1.023 = 2×0.5113）。发现信号：入场价 ≈ 2× 触发价
- **幻影判据失效**：空单开仓本身就是 SELL+pnl=0，与"同秒对冲"同形。08-06 旧审计据此判 12 笔幻影单，08-10 全量复验全部为误判（那 12 笔都有真实盈亏，3 秒窗口反向双零检测命中 0）。本系统无幻影单
- **TP1 减半**：不产生新 round trip，剩余仓位最终平仓才收尾；部分止盈识别 = 平仓 fills 里既有 pnl>0 腿又有后续 pnl≤0 腿

## 闭合校验（必须做）

Σ(已完成 round trip pnl) + Σ(在持仓已实现 pnl) == Σ(全量 userTrades realizedPnl)，差必须为 0。08-10 实测：-11.23 + 1.43 = -9.80 ✓

## 08-10 终版数字

42 开仓 / 40 完整平仓（胜16负24，净 -12.04U 不含手续费；含手续费 -16.2U）/ 2 在持（NEAR 空、SOL 多）/ 剔除 TRX 遗留 2 笔 +0.81U。
