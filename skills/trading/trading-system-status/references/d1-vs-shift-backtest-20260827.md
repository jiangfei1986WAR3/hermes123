# D1(保留结构位缩仓) vs 等距平移：真实账本平行世界回测（2026-08-27）

用户探讨"滑点后 TP1 平移越过前高，结构止盈是否失效"引出 D1 方案定量对比。结论用户定调："**不能说绝对优势，只能说更稳**"。PROPOSED / NOT ACTIVE，系统零改动。

## 回测方法（可复用，纯读取不做任何写）

1. 账本定位 `~/.hermes/trading-history/YYYYMMDD_HHMMSS_符号.json`：结构 = 顶层 `{"plan": {...}, "execution": {...}}`；写回字段**都在 plan 内**（`plan.actual_entry` / `plan.slippage`）；plan.stop_loss / take_profits 是**平移后**写回值 → 原值 = 写回 − slippage（做多）。execution.steps 的 calc_params 含真实 quantity。
2. 结局路径：userTrades 按天分片拉，`time` 毫秒；⚠️ 北京时区 02:00 附近的成交落在**前一 UTC 日**，分片起点往前多拉一天（XMR 08-25 02:32 开仓在 08-24 UTC 分片）。
3. 平行推演：1m klines 判关键触发顺序 + 15m 判平仓后延续段；D1 qty = `qty_orig×(trigger−SL_orig)/(E−SL_orig)` 按币精度取整；TP 成交按触发价计；TP1 后剩半仓移保本 E（两版一致）。
4. 误差声明：同分钟先高后低不可分辨（天地针分钟 ±1U 级）；未平仓位按现价浮亏计并标"未了结"。

## 结论

- 亏损单合计：**-12.60 → -5.62**；盈利单（FIL）：**+5.16 → +2.91**。= D1 把两头往中间收（方差收窄），**不是均值升高**——6 笔（含 1 未了结）不够谈期望。
- D1 优势三机制：①TP1 更近提前落袋 ②移保本更早接管 ③结构止损躲过"结构外被扫"。代价一机制：趋势单缩仓少赚（FIL 已兑现）。
- 讨论定调：D1 是偏好题——拿盈利弹性换亏损尾部；用户亏后情绪反应更痛，气质匹配 D1，但大行情吃小份只有用户能拍板。
