# 八态频谱与统一判定树

## 统一判定树（唯一入口）

```
第一步：是否存在有序波段序列？
  有 HH+HL（至少2组以上）→ 通道候选（看涨）
  有 LL+LH（至少2组以上）→ 通道候选（看跌）
  无（序列缺失/被打断/仅1组）→ 区间态

第二步（通道态）：波段序列是否达到3组以上且可画出平行趋势线？
  是 → 判断回撤深度：
    回撤 < 30% → tight_channel（窄/紧凑通道）
    回撤 30%~50% → normal_channel（常规通道）
    回撤 50%~78.6% → broad_channel（宽通道/台阶）
  否（仅2组序列，或趋势线画不稳定）→ trending_tr

第三步（区间态）：是否存在清晰的上下边界（各 ≥ 2 次测试）？
  有清晰边界，EMA 水平或接近水平 → trading_range
  方向完全丧失、EMA 纠缠、任意入场期望值为负 → extreme_tr
```

## 状态1：尖峰（Spike）

**定义**：最强势趋势形态，由≥1根同方向强趋势棒形成的突破性运动，回撤极小，带有"行为性紧迫感"。

**统一 Spike 分级**：
- **弱尖峰候选**（1根）：恰好1根超大突破棒+下一根有跟随 → 只记录 spike_candidate，不输出 cycle_position=spike，禁止追单
- **最低可路由尖峰**（2根）：2根以上连续趋势棒，实体重叠<30% → 可输出 spike；仅SPS，禁止SCS
- **标准尖峰**（3~5根）：实体重叠<20%，几乎无尾线 → 仅SPS/尖峰旗形顺向突破，禁止SCS
- **强尖峰/高潮风险**（6根以上，或任意序列+衰竭信号）→ climax_risk=warning/triggered，禁追

**高潮判定**：任意连续强趋势棒序列 + 出现以下任一衰竭信号：
- 长尾线（尾线>实体50%）
- 小实体棒（实体<均值30%）
- 反向趋势棒

**尖峰后概率分布**：60%恢复通道 / 30%进区间 / 10%反转

**spike vs micro_channel 裁决**：同时满足尖峰最低标准 → 优先 spike；仅2~10根紧凑推进但未达尖峰标准 → micro_channel

## 状态2：微型通道（Micro Channel）

- 2~10根K线，几乎无回撤
- 第一个突破尝试失败率>80%
- 利用假突破失败后的顺通道入场
- 须填 spike_stage

## 状态3：紧凑通道（Tight Channel）

- 回撤<30%（主判定），趋势棒>65%，K线重叠<20%
- 只做顺势，禁止逆势
- 首选 H1/H2 回撤买入（上涨）或 L1/L2 反弹卖出（下跌）
- 不追通道边界突破

## 状态4：常规通道（Normal Channel）

- 回撤30%~50%，波段清晰
- 只做顺势，禁止逆势
- 顺势入场：回撤到38.2%~50%区域出现信号棒
- 上涨通道在长程结构窗口上是空头旗形

## 状态5：宽通道（Broad Channel / Staircase）

- 回撤50%~78.6%，≥3组HH+HL/LL+LH
- 仅顺主方向，禁止通道对侧逆势刮头皮
- 核心模式：突破后不追，等突破测试后顺主方向入场
- 几乎每次突破后都有突破测试

**宽通道 vs trending_tr**：
- 有3组以上且可画稳定通道线 → broad_channel
- 仅2组或通道线不稳定 → trending_tr

## 状态6：趋势型交易区间（Trending TR）

- 宽通道退化形式，方向偏好但序列不完整
- 仅顺direction一侧边界/回撤入场
- 中部禁止先入

## 状态7：交易区间（Trading Range）

- 清晰上下边界，EMA水平
- 仅顺direction一侧边界等待
- neutral时倾向wait
- 突破80%失败，不追

## 状态8：极端交易区间（Extreme TR）

- 方向完全丧失，EMA纠缠
- 最好不交易，任何入场接近抛硬币
- 宁可多观察几根K线再确认

## 单周期多尺度嵌套

**核心原则**：只输入单一周期的100根K线，不假设外部周期。

**三窗口关系**：
- 三窗口同向 → 最强信号
- 长程≠近期 → 不否决近期方向，近期为主，背景作风险提示
- Brooks："新趋势比旧有趋势更能代表当前的现状"

**常见场景**：
1. 长程尖峰+近期回撤 → 顺势入场机会
2. 长程区间+近期微型通道 → 仅当方向与direction一致时顺势
3. 长程宽通道+近期尖峰突破 → 等回踩测试后顺势
4. 长程趋势+近期趋势型TR → 等区间结束趋势恢复
5. 长程AIS+近期多头尖峰 → 近期方向为主，背景作风险提示
6. 长程AIL+近期空头尖峰 → 对称处理

## 通用转换规则

1. 转换期间减少交易频率到正常一半
2. 转换确认后再调整策略
3. 信号不明确时维持当前策略
4. 每次转换后重新评估三窗口
