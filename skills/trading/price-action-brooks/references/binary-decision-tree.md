# 二元决策树完整流程

## 核心顺序
1. 先判断市场状态 → 2. 方向偏好 → 3. 入场信号 → 4. 风险收益 → 5. 交易者方程裁定 → 6. 下单方式

## §0 总原则
- §0.1 看得懂？否→等待
- §0.2 具备深入分析条件？（定性，非数值）否→等待
- §0.3 交易者方程原则提醒（最终裁定在§10.3）

## §1 是否可以决策
- §1.1 数据≥20根？否→等待
- §1.2 能识别周期？否→unknown，等待
- §1.3 极端混乱？是→不交易

## §2 多空方向判断
- §2.1 明确惯性方向？否→区间逻辑
- §2.2 长程vs近期方向关系：同向→提高置信；反向→不否决近期，近期为主
- §2.3 当前方向：多头(EMA上倾+HH+HL) / 空头(EMA下倾+LL+LH) / 中性
- §2.4 Always In：AIL(近端K8多数收EMA上方) / AIS(下方) / 否
  - 20GB特殊规则：连续~20根未触EMA，绝不逆势，首次触EMA是顺势机会
- §2.5 惯性强度够？否→不短路，切换为"等反弹到位后顺势信号"模式

## §3 尖峰/极速行情
- §3.1 满足尖峰条件？（按分级定义）
- §3.2 仍在进行？是→只顺势不反转
- §3.3 允许追？**否（硬规则，禁止SCS）**
- §3.4 第一次暂停/回撤？→SPS入场或尖峰旗形顺向突破
- §3.5 尖峰后路径：A(回撤<50%→通道60%) B(回撤>61.8%→区间30%) C(反转10%→仅诊断)
- §3.6 高潮？→禁追原方向，仅wait或回撤后SPS
- §3.7 第二/三次高潮→不追，wait

## §4 通道判断
- §4.1 有序波段结构？HH+HL≥2组→通道候选
- §4.2 方向：上涨通道=空头旗形，下跌通道=多头旗形

## §5 通道宽度
- §5.1 微型通道→不逆势，等突破失败后顺势
- §5.2 紧凑/窄通道→只做顺势，H1/H2回撤入场
- §5.3 常规通道→顺势，回撤38.2%~50%信号棒
- §5.4 宽通道→仅顺主方向，突破后等测试
- §5.5 收缩台阶→降confidence，禁止逆势

## §6 交易区间
- §6.1 清晰上下边界？
- §6.2 普通TR vs 趋势型TR
- §6.3 价格在边界？中部1/3→不交易
- §6.4 Barbwire？→不交易
- §6.5 突破？高质量(3~5根强趋势棒)→等回踩；低质量→wait
- §6.6 三角形→按类型+direction门控

## §7 反转（仅诊断，禁止逆势下单）
- §7.1 单根反转K线→不够
- §7.2 趋势线突破+极点测试失败→仅提高诊断置信度，禁止逆势入场
- §7.3 二次入场（顺势H2/L2可用；逆势禁止）
- §7.4 二次入场失败→不做第三次

## §8 楔形/三推
- §8.1 三推结构？
- §8.2 楔形回撤(与主趋势相反,<20棒)→顺势入场 / 楔形反转(同向,≥20棒)→仅诊断
- §8.3 抛物线楔形→禁止追趋势、禁止追高潮

## §9 入场信号检查
- §9.0 信号棒已收盘且质量够？否→必须评估§9.0P
- §9.0P 背景驱动限价单：周期+方向+结构位支持→可输出限价单
  - 仅顺direction/Always In一侧
  - direction=neutral时默认wait
  - 定价顺序：entry→TP1→TP2→stop
- §9.1 已收盘？
- §9.2 方向一致？
- §9.3 过长？→风险过大
- §9.4 第一次入场？（逆势仅诊断）
- §9.5 有跟随？
- §9.6 二次入场？（胜率更高）
- §9.7 入场棒强势？

## §10 风险收益
- §10.1 能明确止损？（结构失效位，非固定跳数）
- §10.2 止损过大？（>止盈距离/通道宽40%/区间宽10%/2×ATR）
- §10.3 交易者方程：胜率×回报 > 败率×风险（仅用TP1），RR≥1.0

## §11 下单方式
- 趋势/尖峰→止损单（SPS/旗形突破）
- 通道回撤→限价单(窄)/止损单(常规)/限价或止损(宽，须近边界)
- 交易区间→止损单等确认/限价单(边界)
- 突破→禁止SCS追第一棒，等回踩测试

## §14 禁止行为清单
- 未识别周期就交易
- 极端TR中交易
- 尖峰中做反转
- 高潮后追原方向/SCS
- 区间追普通突破
- 区间中部入场
- 宽通道追突破
- 任何逆势（含边界刮头皮、MTR反手）
- AIL中做空/AIS中做多
- order_direction与direction不一致
- 因§7/mtr/楔形反转产出逆势三价
- 二次入场价明显优于第一次仍强行
- 二次入场失败后第三次
- 信号棒过长仍强行
- 交易者方程不通过仍下单
- 为凑方程扭曲结构止损

## §15 最终执行口诀
1. 看不懂，等
2. 极端混乱，等
3. 尖峰中只顺势，禁止SCS/追高潮
4. 通道/区间只顺direction，禁止逆势
5. 宽通道不追突破
6. 区间中仅顺direction一侧，neutral则wait
7. 反转/MTR只诊断不下单
8. 楔形回撤可顺势，末端楔形禁止追顺势/逆势
9. 信号必须等收盘
10. 止损和方程不过关，放弃
