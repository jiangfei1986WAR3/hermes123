# 止损止盈、交易者方程、Measured Move、MTR、禁止行为

## 一、保护性止损（入场前确定）

### 统一止损原则
止损位置永远基于**结构失效位**，不基于固定跳数。固定跳数仅作风险过滤器。

**通用规则**：止损 = 信号棒极点外1跳
- 做多：信号棒低点下方1跳
- 做空：信号棒高点上方1跳

### 各市场状态止损位置
| 状态 | 止损设置 | 过滤器（超过则放弃） |
|------|---------|---------------------|
| 尖峰回撤SPS | 回撤极点外1跳 | >尖峰高度50% |
| 普通趋势/通道顺势 | 信号棒极点外1跳 | >通道宽40%或>2×ATR |
| 普通区间边界 | 信号棒极点外1跳 | >区间宽10% |
| 宽通道（噪声大） | 信号棒极点外1跳；扩至波段极点外1跳 | >通道宽50% |
| 铁丝网 | 不做，或突破棒极点外1跳 | 边界外1-2跳无效 |
| 反转/MTR | 不产出逆势三价 | — |

### 止损过大判断（§10.2）
以下任一成立即过大（放弃或等更小信号）：
- 止损 > 止盈目标距离（RR<1:1）
- 止损 > 通道宽度40%
- 止损 > 区间宽度10%
- 止损 > 2倍ATR
- 8跳/信号棒60%高度仅作辅助参考，不替代结构止损

## 二、获利目标（TP1 + TP2）

### TP1（take_profit_price）— 主目标
- 参与§10.3交易者方程与RR校验
- RR≥1.0（RR>1.0时程序自动向外扩stop）
- 来源优先级：
  1. 反向结构边界（近端）：区间近对边、通道近端、前swing
  2. 磁力位：失败信号棒极点、失败入场价
  3. 固定R倍数（≥1R）：仅当无更近结构位时兜底

### TP2（take_profit_price_2）— 延伸目标
- 必填，不参与§10.3
- 来源：Measured Move、通道对边远端、区间高度翻测

### 几何硬规则
- 做多：stop < entry < TP1 < TP2
- 做空：TP2 < TP1 < entry < stop

### 定价顺序
1. 定entry（结构位/边界/回撤位）
2. 定TP1（最近有效结构目标）
3. 定TP2（更远结构目标）
4. 定stop于结构失效位
5. RR>1.5：保持TP不变，程序自动扩stop
6. RR<1.0：收紧stop或调整entry，禁止向外扩stop
7. 仍<1.0 → reject

### 禁止
- 缩小TP1来迎合RR
- 用TP2参与§10.3
- 把K1区间内部/EMA噪音当TP1

## 三、交易者方程（§10.3）

**公式**：胜率 × 回报 > 败率 × 风险
- 回报、风险仅来自 entry / stop / TP1
- RR = 回报 ÷ 风险，须≥1.0
- 有下单时 estimated_win_rate 必填
- 不下单时三价与win_rate均为null

## 四、Measured Move（MM，测量移动）

### 定义
根据已完成的一段价格运动（leg），向突破/延续方向等距投影的预期目标区。

### 四类MM计算

#### 1. 震荡区间突破MM
- 区间高度H = 上沿 − 下沿
- 向上突破：目标 ≈ 突破点 + H
- 向下突破：目标 ≈ 突破点 − H
- 概率：有效突破后约60%可达

#### 2. 通道MM
- 通道宽度W = 上轨 − 下轨
- 顺势突破通道线：目标 ≈ 突破点 ± W

#### 3. 楔形MM
- 楔形高度H = 起点到极点距离
- 突破对侧边界后：目标 ≈ 突破点 ± H

#### 4. 尖峰/趋势leg MM
- 取尖峰起点到终点距离L
- 回撤后再延续：目标 ≈ 回撤低点 + L
- 概率：强趋势leg顺势约70%+
- 向外扩stop不得超过尖峰高度50%

### MM使用注意
- MM是结构目标，不是下单理由
- 须同时满足§9入场依据与§10.1-10.3
- MM常作TP2；若作TP1且RR>1.0，扩stop

## 五、MTR（主要趋势反转）

### 定义与概率
- 完整MTR第一次反转成功率约35-40%
- 第二次反转尝试概率约40%
- 一般反转尝试失败率约80%

### 四组件（缺一不可标mtr）
1. 原趋势存在（清晰HH+HL或LL+LH）
2. 趋势线/通道突破（收盘确认，非毛刺）
3. 趋势恢复失败（无强跟随、无新高/低）
4. 前极点测试失败（无法创新高/低）

### PA Agent强制输出
- order_type = 不下单（无例外）
- terminal.outcome = wait
- 仅诊断 + watch_points
- 禁止逆原趋势三价

### MTR vs 其他标签
| 标签 | 含义 |
|------|------|
| reversal_attempt | 有反转迹象，未完整 |
| mtr | 四组件齐全（仍仅诊断） |
| final_flag | 趋势末端旗形 |
| wedge | 三推楔形 |
| MRV | 小级别反转，多半只是回撤 |

## 六、Final Flag（最终旗形）

- 趋势运行较长时间后出现水平重叠整理（10-20+棒）
- 位于趋势末端、近MM或极值 → 标final_flag
- 顺趋势突破旗形1-2根无跟随 → 失败FF，勿追
- 反向信号棒+入场棒 → 仅诊断，禁止逆势三价
- 整理区呈铁丝网 → 中部不交易

## 七、磁力位（Magnet）

- 失败信号棒极点、失败入场价 → 价格倾向于回到这些位置
- 17t/41t类陷阱区不作止损/entry
- 写入watch_points/invalidation_condition

## 八、禁止行为完整清单

1. 未识别周期位置就交易
2. 数据不足仍下单
3. 极端TR中交易
4. 尖峰中做反转
5. 高潮后追原方向（含SCS）
6. 使用SCS或任何尖峰追单路径
7. 区间追普通突破
8. 区间中部入场
9. trending_tr中做中部趋势跟踪或追突破
10. 宽通道追突破
11. 常规/宽通道中任何逆势（含边界刮头皮、MTR反手）
12. AIL中做空/AIS中做多
13. order_direction与direction/Always In不一致
14. 因§7/mtr/楔形反转产出逆势三价
15. 用长外包棒两端突破直接入场
16. 二次入场价明显优于第一次仍强行
17. 二次入场失败后第三次（含末端楔形三推）
18. 信号棒过长仍强行
19. 止损距离过大仍强行
20. 交易者方程不通过仍下单
21. 为凑方程扭曲结构止损
22. 止损后立即反手
23. 连续两笔止损后不重新评估
