# 通道策略 + 楔形/三推 + 二次入场 + 突破

## 一、通道分类与策略

### 窄/紧凑通道（Tight Channel）
- 回撤<30%，趋势棒>65%，K线重叠<20%
- 只做顺势，禁止逆势
- 入场：H1/H2回撤买入（上涨）/ L1/L2反弹卖出（下跌）
- 突破失败入场：价格突破趋势线后迅速回通道内 → 最佳入场点
- 止损：信号棒极点外1跳
- 第一个逆势突破通常失败

### 常规通道（Normal Channel）
- 回撤30%~50%，波段清晰
- 只做顺势，禁止逆势
- 入场：回撤到38.2%~50%区域出现信号棒
- 上涨通道=空头旗形（长程结构窗口），上方有阻力

### 宽通道/台阶（Broad Channel / Stairs）
- 回撤50%~78.6%，≥3组HH+HL/LL+LH
- 仅顺主方向，禁止通道对侧逆势
- 核心：突破后不追，等突破测试后顺势入场
- 几乎每次突破后都有突破测试
- 止损：信号棒极点外1跳；噪声大时扩至波段极点外1跳

### 微型通道（Micro Channel）
- 2~10根，几乎无回撤
- 第一个突破失败率>80%
- 等突破失败后顺势入场
- 止损：突破极点外1跳

### 收缩台阶
- 每段推进幅度递减，动能衰退
- 降trade_confidence，禁止逆势三价
- 不追最后一推

### 通道转换信号
- 窄→宽：出现较大反向K线、回撤触及趋势线、重叠增多
- 宽→窄：回撤越来越小、实体变大、连续趋势棒
- 宽→区间：价格在边界间震荡无方向
- 任何→反转：仅诊断，禁止逆势三价

## 二、楔形/三推

### 楔形本质
- 楔形 = 三推（Three Pushes），每次推进幅度递减
- 趋势线和通道线逐渐收敛
- 第一推动量最强，第三推动量显著不足

### 楔形回撤 vs 楔形反转（最重要区分）
| 特征 | 楔形回撤 | 楔形反转 |
|------|---------|---------|
| K线数量 | 10-20棒 | ≥20棒 |
| 方向 | 与主趋势相反 | 与主趋势相同 |
| 突破后 | 回到原趋势方向 | 趋势反转 |
| 交易 | 顺势入场（§9/§10.3） | 仅诊断，禁止下单 |

### 判断方法
- 楔形方向与主趋势相反 → 楔形回撤（顺势机会）
- 楔形方向与主趋势相同 → 楔形反转（仅诊断）
- <20棒偏向回撤，≥20棒偏向反转

### 抛物线楔形
- 价格加速推进，每推斜率更陡
- = 买入/卖出高潮
- 禁止追原方向，禁止逆势反手
- 仅wait + watch_points

### 微楔形（3-4棒）
- 极小楔形，短期动能衰减
- 不单独作为入场依据
- 须结合其他信号

### 楔形回撤交易规则
- 上涨趋势中下降楔形：向上突破做多
- 下跌趋势中上升楔形：向下突破做空
- 止损：楔形极点外1跳
- 目标：楔形起点 + 楔形高度MM

## 三、二次入场

### 为什么需要二次入场
- 第一次反转尝试多数失败（~80%）
- 第二次信号通常更可靠
- 60/40规则：60%交易是小盈亏，真正优势在大利润>>大亏损

### 顺势二次入场（可评估三价）
- H2/L2：第二腿回撤后再次突破前棒极点
- 突破回踩：突破后回测突破点
- 区间边界顺direction第二次测试

### 逆势二次入场（仅诊断，禁止三价）
- 楔形反转、MTR、双重顶底反手、趋势线逆突破

### H1/H2/L1/L2 计数
- H1：第一腿回撤后第一根突破前棒高点
- H2：第二腿回撤后再次突破
- H3：常演变为楔形牛旗，不宜盲目追
- 计数清零：新swing形成/Always In翻转/强突破+跟随

### 何时H1可做
- 强趋势/微型通道/紧凑通道顺势
- Always In明确，信号棒质量高，入场棒强

### 何时必须等H2/L2
- MTR/楔形反转后
- 趋势线突破回测
- 交易区间边界第二次测试
- 第一次信号棒quality=weak

### 二次入场陷阱
- 价格明显优于第一次 → 可能是陷阱
- 二次入场失败 → 不做第三次
- 等待超过2小时 → 信号失效

## 四、突破失败与突破测试

### 核心法则
- 区间中约80%突破失败
- 趋势中约80%反转尝试失败
- 改变惯性需要：强突破棒+跟随

### 普通突破（默认不追）
- 仅1-2根刺破，影线明显，无跟随
- 处理：wait或§9.0P计划型限价

### 尖峰级突破（等回踩，禁止SCS）
- 连续3-5根同向强趋势棒
- 禁止追第一棒，等回踩测试后且方向与direction一致

### 真突破三条件
1. 跟随：突破后1-2根同向K线
2. 缺口：均线缺口/实体缺口/无重叠
3. 强势突破棒：大实体短影线

### 突破失败（Failed Breakout）
- 突破棒后无跟随，快速回原结构
- 不凭单根失败棒反手，禁止逆势三价

### 失败的失败（Failed Failure）
- 突破失败本身失败，价格重新回原突破方向
- 可靠的二次入场机会
- 优先H2/L2框架

### 突破测试（Breakout Test）
- 回踩接近突破点但未跌回结构内
- 测试棒成为顺突破方向的信号棒
- 测试后入场棒强，有跟随

## 五、铁丝网（Barbwire）

### 特征
- 紧凑度<25%（区间宽度/平均波段高度）
- ≥3根K线高度重叠且至少1根十字星/小实体
- 连续十字星、长影线，绕EMA穿梭
- 位于交易区间中部

### 交易含义
- 大部分信号忽略
- 单根十字星/内包棒无交易价值
- 外包棒=更大单棒区间，禁止两端追突破
- 优先级覆盖H1/H2、OB、ii/iii等信号

### 可交易例外（须逐项说明）
1. 价格接近清晰区间边界（非中部）
2. 一方明显被套+强入场棒跟随
3. 铁丝网后尖峰级突破+跟随
4. 第二次边界入场+止损很小

## 六、Always In 与 20GB

### AIL（Always In Long）
- 近端K8多数收EMA上方，回撤浅
- 多头趋势棒有跟随，HH+HL
- AIL中首个做空反转 → 仅诊断，禁止

### AIS（Always In Short）
- 对称处理

### 20GB
- 连续~20根未触EMA → 趋势极强
- 绝不逆势
- 首次触EMA是顺势刮头皮机会
- 两次失败后不做第三次
