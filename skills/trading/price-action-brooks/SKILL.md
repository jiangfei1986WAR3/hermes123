# Al Brooks 价格行为（Price Action）完整知识体系

基于 PA_Agent 项目（github.com/rosemarycox5334-debug/PA_Agent）提炼的 Al Brooks 价格行为分析框架。覆盖市场诊断（八态频谱）→ 二元决策树 → K线信号 → 入场/止损/止盈全流程。不依赖成交量，不依赖指标，仅解读K线结构与EMA20。

## When to Use

- 分析K线图时需要判断市场周期位置（尖峰/通道/区间）
- 需要按二元决策树做交易决策（是否入场、方向、三价）
- 识别K线信号（信号棒/入场棒/外包/内包/2BR/缺口棒）
- 判断通道类型与对应策略（窄/常规/宽通道）
- 评估楔形/三推/二次入场/突破失败等形态
- 计算止损、止盈、交易者方程
- 需要理解 Always In、20GB、铁丝网等概念

## Prerequisites

无特殊依赖。本 Skill 为纯知识参考，可配合 `trading-analysis` Skill 和 `fetch_klines.py` 使用。

## Quick Reference

### 四条全局硬禁令（最高优先级）
1. **禁止逆势**：order_direction 不得逆 direction / Always In / 近期主方向
2. **禁止追高潮**：climax_risk 预警/触发后禁追原方向，禁止 SCS
3. **禁止仓位管理**：不输出手数、比例、分批、移止损、跟踪止损
4. **不依赖成交量**：识别与决策不以成交量为必要条件

### 八态频谱（强→弱）
| # | 状态 | 英文 | 核心特征 |
|---|------|------|----------|
| 1 | 尖峰 | spike | ≥2根连续趋势棒，实体重叠<30%，无回撤 |
| 2 | 微型通道 | micro_channel | 2~10根，几乎无回撤 |
| 3 | 紧凑通道 | tight_channel | 回撤<30%，趋势棒>65% |
| 4 | 常规通道 | normal_channel | 回撤30%~50% |
| 5 | 宽通道 | broad_channel | 回撤50%~78.6%，≥3组HH+HL |
| 6 | 趋势型交易区间 | trending_tr | 方向偏好但序列<3组 |
| 7 | 交易区间 | trading_range | 清晰上下边界，EMA水平 |
| 8 | 极端交易区间 | extreme_tr | 方向完全丧失，不交易 |

### 关键概率锚点
- 区间突破约 **80% 失败**
- 一般反转尝试约 **80% 失败**变旗形
- 完整 MTR 成功率约 **35–40%**（仅诊断，不下单）
- 尖峰后约 **60%** 恢复通道 / 30% 进区间 / 10% 反转
- H2/L2 优于 H1/L1（顺势回撤场景）
- 区间有效突破约 **60%** 可达 Measured Move
- 强趋势 leg 顺势延续 MM 约 **70%+**

## Procedure

### 阶段一：市场诊断（读懂市场）

1. **第一层：周期频谱定位** — 用统一判定树判断 cycle_position
   - 有HH+HL/LL+LH → 通道候选 → 按回撤深度分 tight/normal/broad
   - 无有序序列 → 区间态 → trading_range 或 extreme_tr
2. **第二层：市场背景评估** — 五维背景（趋势方向/强度/阶段/价格位置/嵌套）
3. **第三层：逐K信号确认** — K10–K1 即时窗口信号棒/跟随/结构

### 阶段二：交易决策（二元决策树）

按 §0→§14 顺序逐步判断：
1. §0–§2 闸门：看得懂？数据够？方向？Always In？惯性？
2. §3 尖峰判断 → §4–§5 通道判断 → §6 区间判断
3. §7 反转（仅诊断）→ §8 楔形/三推
4. §9 入场信号检查 → §9.0P 计划型限价
5. §10 风险收益（止损→止盈→交易者方程）
6. §11 下单方式 → §14 禁止行为清单

### 止损/止盈/交易者方程

- **止损** = 信号棒极点外1跳（结构失效位，非固定跳数）
- **TP1** = 最近有效结构位（参与 §10.3，RR≥1.0）
- **TP2** = 更远结构目标（MM/通道对边，必填，不参与 §10.3）
- **交易者方程**：胜率×回报 > 败率×风险（仅用TP1）
- 定价顺序：entry → TP1 → TP2 → stop；RR>1.0 保持TP不变扩stop

## Pitfalls

- 尖峰中做反转（胜率极低，禁止逆势三价）
- 区间追普通突破（80%失败，等回踩测试）
- 忽略嵌套窗口（只看K10–K1会误判）
- 单K线当反转（须趋势线突破+极点测试失败双确认）
- 高潮后追原方向（含SCS，禁止）
- 止损贴噪音（须结构失效位）
- 极端TR强行交易（期望值为负）
- 末端三推/楔形反转时追顺势（应wait）
- 宽通道追突破（几乎每次都有突破测试）
- 铁丝网/区间中部给三价（默认不交易）
- 二次入场价明显优于第一次（可能是陷阱）
- 二次入场失败后做第三次（禁止）
